# Government Radar for Gemini CLI

Ask Gemini CLI about the latest Canadian federal and provincial government news releases. Every answer links to the official release.

```bash
gemini extensions install https://github.com/governmentradar/govradar-gemini-extension
```

Free, no account. Covers the last 7 days, up to 5 results per request. Docs: https://www.govradar.ca/ai-plugin

Full archive and daily email digests: https://www.govradar.ca
